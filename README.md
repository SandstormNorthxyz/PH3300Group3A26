# PH3300Group3A26

## Required
- python3
- matplotlib

## Usage
- `python3 potential.py`

Displays plots for the analytical and numerical solutions of 
the electric potential along the z axis for a thin disk centered at the origin in the x-y plane
of radius 0.15m and area charge density 5e-6 c/m^2 for 
various values of N (number of trapezoids in integral approximation).
